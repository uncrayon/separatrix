# Keyboard shortcuts

On macOS, use ⌘ where this page says Ctrl. The shortcuts read the key's position as well as its
letter, so they also work on Greek, Cyrillic and other keyboard layouts.

## Projects

| Keys | Action |
| --- | --- |
| Ctrl+N | New system. Desktop app only. |
| Ctrl+O | Open a project. Also works while the template gallery is open. |
| Ctrl+S | Save. |
| Ctrl+Shift+S | Save as. |
| Ctrl+E | Export. |

## Phase plane, time series, cobweb and section

Focus the plot first with Tab, or click it, which also adds a trajectory. A keyboard cursor then
marks a point on the plot.

| Keys | Action |
| --- | --- |
| Arrow keys | Move the cursor by 1/40 of the view. In a cobweb, the cursor moves along the diagonal. |
| Shift+arrow keys | Move the cursor 5 times as far. |
| Enter or Space | Select the trajectory or fixed point under the cursor, or add a trajectory there. |
| F | Select the next fixed point. |
| Shift+F | Select the previous fixed point. |
| Plus or = | Zoom in by 1.25 around the cursor. |
| Minus or _ | Zoom out by 1.25 around the cursor. |
| 0 | Reset the view. |
| Delete or Backspace | Delete the selected trajectory. |
| Escape | Deselect. |

## 3D view

| Keys | Action |
| --- | --- |
| Left and Right arrows | Turn the box by 5° about the vertical axis. |
| Up and Down arrows | Tilt the box by 5°. |
| Shift+arrow keys | Turn or tilt by 15°. |
| Plus or = | Zoom in by 1.25. |
| Minus | Zoom out by 1.25. |
| 0 | Reset the camera. |

## Lyapunov, orbit diagram and Branch views

| Keys | Action |
| --- | --- |
| Arrow keys | Pan by 1/20 of the view. |
| Shift+arrow keys | Pan by 1/4 of the view. |
| Plus or = | Zoom in by 1.25. |
| Minus or _ | Zoom out by 1.25. |
| 0 | Zoom to fit. |

## Equations and parameters

| Where | Keys | Action |
| --- | --- | --- |
| An equation line | Enter | Add a line below. |
| The LaTeX and Text switch | Arrow keys | Switch the input mode. |
| A parameter slider | Left and Right, or Down and Up | Step by 1/100 of the slider's range. |
| A parameter slider | Page Down and Page Up | Step by 1/10 of the range. |
| A parameter slider | Home and End | Go to the minimum or the maximum. |
| A parameter's number box | Up and Down | Step by 1/100 of the range, or 1/10 with Shift. |
| A parameter's number box | Enter | Apply the typed value. |
| A parameter's number box | Escape | Go back to the current value. |

## Toolbars and menus

| Where | Keys | Action |
| --- | --- | --- |
| The plot's toolbar | Left and Right arrows | Move between buttons. |
| The plot's toolbar | Home and End | Go to the first or the last button. |
| The plot's toolbar | Escape | Hide the button's tooltip. |
| The axes menu | Up and Down arrows | Move between items. |
| The axes menu | Escape | Close the menu. |
| A dialog | Escape | Close it. The gallery stays open on first launch, until you pick a system. |

## Mouse

| Action | Result |
| --- | --- |
| Click the plot | Add a trajectory, or an orbit in a cobweb, starting there. |
| Drag a start point | Move it. |
| Drag empty space | Pan. In the 3D view, turn the box. |
| Scroll | Zoom. |
| Double-click | Reset the view. In the Lyapunov view, zoom to fit. |
| Click the orbit diagram or a branch | Set the parameter there. |
